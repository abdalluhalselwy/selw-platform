# ADR-0004: قرارات القسم 16 المؤجلة إلى المرحلة 2

- **الحالة:** Open؛ لا حسم هنا. الخيارات التالية قائمة للنقاش وليست توصيات نهائية.
- **التاريخ:** 2026-11-20
- **السياق:** `AGENTS.md` §16 يجعل عشرة قرارات مفتوحة تتطلب ADR وموافقة. بعضها يؤثر في التصميم الحالي، لذا نعرض البدائل دون اختيار.

| القرار | خيارات أولية للمقارنة | أسئلة/مخاطر؛ التوفر والتفاصيل `NOT VERIFIED` |
|---|---|---|
| Queue/Workers | ARQ، Celery، بديل متوافق | خبرة الفريق، async، retries/DLQ، التشغيل والتكلفة |
| مزود الدفع | مزود عالمي، إقليمي أو تكامل بحسب السوق | دعم SAR/AED/EGP، التسوية والاشتراكات والاسترداد والامتثال |
| Data Residency | موقع واحد، مواقع إقليمية، توزيع حسب المؤسسة | مكان DB/API/Workers/Redis/backups/LLM؛ قانوني وتعاقدي |
| تشفير tokens وإدارة الأسرار | KMS/secret manager، envelope encryption مُدار ذاتياً | تدوير المفاتيح، الفصل، الاستعادة، صلاحيات العاملين والكلفة |
| AI observability | self-hosted، SaaS مع redaction، telemetry داخلية | prompt/PII retention، الإقامة، الوصول والكلفة |
| LLM providers/routing | مزود واحد مبدئياً، أو عدة مزودين | العربية، structured output، latency، الأسعار، DPA، regions، fallback |
| البريد | transactional provider مُدار أو بديل | التسليم، SPF/DKIM، المنطقة، DPA، كلفة الاستخدام |
| أولوية integrations | اختيار مبني على مقابلات العملاء والسوق أو شريحة أولية | API الرسمية، موافقات المنصات، الجهد والعائد |
| تغطية الاختبارات | نسبة حد أدنى مع quality gates، أو gates نوعية فقط | المقترح في AGENTS.md يذكر 80% للوحدات الأساسية؛ تعريف القياس مطلوب |
| retention/deletion | مدد حسب نوع البيانات مع استثناءات/حفظ قانوني | متطلبات الأسواق، النسخ الاحتياطية، التصدير والحذف، audit immutable |

- **القرار:** نقل هذه الخيارات للمرحلة 2؛ لكل منها يلزم مقارنة موثقة، مصادر رسمية حديثة عند انطباقها، أثر أمني/تشغيلي/تجاري، ثم موافقة صريحة. لا تُعامل أي خانة كاختيار معتمد.
- **المراجع:** `AGENTS.md` §§0, 7.3, 9, 12, 16.
